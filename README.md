# Week 3 - Software Testing and Debugging Exercise

## Objective
This mini project demonstrates unit testing, debugging, bug fixing, refactoring, and test coverage.

## Module
Calculator Utility Module

## Technology
- Node.js
- JavaScript
- Jest

## Workflow
1. Run tests against the intentionally flawed version.
2. Identify failing tests and bugs.
3. Debug and fix the code.
4. Refactor the implementation.
5. Run the complete test suite with coverage.

## Commands
npm install
npm test

For debugging with Node Inspector:
npm run test:debug
